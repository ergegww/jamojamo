자모자모 개인정보처리방침

MewgicPixel(이하 "개발자")은 한글 낱말 맞추기 게임 "자모자모"(이하 "앱")를 제공하며, 이용자의 개인정보를 소중히 다룹니다. 이 방침은 앱이 어떤 정보를 다루는지 설명합니다.

현재 배포본 기준: 클라우드 기록 동기화와 Google 계정 연결은 비활성화되어 있어 게임 기록은 이용자 기기에만 저장됩니다. 광고는 Google AdMob을 통해 표시됩니다.

1. 개발자가 직접 수집하는 정보

게임은 회원가입이나 로그인 없이 바로 이용할 수 있습니다. 현재 배포본에서는 Firebase 로그인과 Google 계정 연결 기능이 꺼져 있어, 개발자가 이용자를 식별하는 계정 정보(익명 UID, 이메일 주소 등)를 수집하지 않습니다. 게임을 마치고 신기록을 남길 때 입력하는 별명과 점수는 이용자 기기 안에만 저장되며 서버로 전송되거나 다른 이용자에게 공개되지 않습니다.

3. Firebase 계정 및 클라우드 동기화

앱에는 Firebase 연동 코드가 포함되어 있지만, 현재 배포본에서는 클라우드 동기화가 꺼져 있어 익명 UID 생성, Google 로그인, Real-time Database 저장, 전체 이용자 순위표 기능이 실행되지 않습니다. 따라서 서버에 저장되는 개인정보나 공개 순위표는 없습니다.

향후 이 기능을 켜는 배포본을 출시할 경우, 이 방침을 먼저 갱신해 수집 항목·보관 기간·삭제 방법을 안내하겠습니다.

4. 광고(Google AdMob)

앱은 Google AdMob을 통해 전면 광고와 보상형 광고(힌트 받기·게임 계속하기)를 표시합니다. 전면 광고는 게임이 끝날 때 표시되고, 보상형 광고는 이용자가 직접 요청할 때만 표시됩니다. 광고를 끝까지 보면 힌트 1개 또는 게임 계속하기 기회가 제공됩니다.

광고 제공 과정에서 Google 등 광고 사업자가 아래 정보를 수집·이용할 수 있습니다.

  • 광고 식별자(Android 광고 ID), IP 주소, 기기 정보(모델, OS 버전, 언어 등)
  • 광고 노출·클릭·시청 완료 등 광고 상호작용 정보
  • 앱 사용 정보(앱 버전, 충돌 정보 등)

이 정보는 광고 게재, 성과 측정, 부정 행위 방지 등에 이용되며, 세부 사항은 Google의 정책을 따릅니다. 개발자는 이용자의 개인정보를 광고 목적으로 직접 수집하거나 판매하지 않습니다.

  • Google 개인정보처리방침: https://policies.google.com/privacy
  • Google이 앱에서 정보를 사용하는 방식: https://policies.google.com/technologies/partner-sites

기기의 설정 > 개인정보 보호(또는 Google) > 광고에서 광고 ID를 재설정하거나 맞춤 광고를 해제할 수 있습니다.

5. 개인정보의 제3자 제공

개발자는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 4항의 광고 제공 과정에서만 Google 등 광고 사업자가 광고 관련 정보를 처리하며, 그 범위를 넘어 이용자의 개인정보를 외부에 제공하지 않습니다.

JamoJamo Privacy Policy

MewgicPixel (hereinafter "Developer") provides the Korean word puzzle game "JamoJamo" (hereinafter "App") and respects users' personal information. This policy explains what information the App handles.

Current build: Cloud score sync and Google account linking are disabled, so game records are stored only on the user's device. Ads are displayed through Google AdMob.

1. Information collected directly by the Developer

The game can be played without sign-up or login. In the current build, Firebase login and Google account linking are turned off, so the Developer does not collect account identifiers that identify users (anonymous UID, email address, etc.). The nickname and score entered when saving a new best score are stored only on the user's device and are not transmitted to a server or published to other users.

Game records (scores, best score, per-mode scores, nickname entered for a new best)Displaying records and on-device rankingsInternal device storage

3. Firebase account and cloud sync

The App contains Firebase integration code, but cloud sync is disabled in the current build, so anonymous UID creation, Google login, Real-time Database storage, and the global leaderboard do not run. Therefore, there is no personal information stored on a server and no public leaderboard.
